Delivered training for the 5-day Faculty Development Program on TinyML and Edge AI for Embedded Systems, covering the complete Edge AI workflow, including sensor data acquisition, feature engineering, machine learning and deep learning model development using Python and PyTorch, ONNX model conversion, and deployment on STM32 microcontrollers using X-CUBE-AI. Through hands-on laboratory sessions, real-time hardware implementation, GitHub-based version control, and industry-oriented mini projects, participants gained practical skills to design, optimize, and deploy end-to-end Edge AI solutions aligned with the industry practices and emerging embedded AI technologies.
